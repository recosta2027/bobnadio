---

O usuário quer um desafio de código da DIO para a seguinte entrada: $input

Interprete o input assim:
- O primeiro termo (ou expressão) é a **tecnologia** (ex: Python, Java, React, SQL)
- O segundo termo é o **nível**: Iniciante, Intermediário ou Avançado
- Se o nível não for informado, assuma **Intermediário**

Gere um **Desafio de Código DIO** fictício, didático e completo em Markdown, seguindo exatamente esta estrutura:

---

# ⚔️ Desafio DIO — [título criativo do desafio]

## 📋 Informações do Desafio
| Campo | Valor |
|-------|-------|
| **Tecnologia** | [tecnologia] |
| **Nível** | [nível] |
| **XP ao Concluir** | [valor entre 500 e 5000, proporcional ao nível] |
| **Categoria** | [ex: Algoritmos, API, Frontend, Backend, Data, DevOps] |
| **Tempo Estimado** | [ex: 2 horas] |

## 🌍 Contexto
Crie um cenário fictício e imersivo que justifique o desafio. Relacione com um problema real de mercado. 3 a 5 linhas.

## 🎯 Objetivo
Descreva em 1 parágrafo o que o desenvolvedor precisa construir ou resolver.

## 📌 Requisitos Funcionais
Liste de 4 a 7 requisitos técnicos que a solução deve atender. Use checkboxes:
- [ ] Requisito 1
- [ ] Requisito 2
...

## 🧪 Critérios de Aceitação
Liste de 3 a 5 condições que indicam que o desafio foi concluído com sucesso.

## 💡 Dicas
Forneça de 3 a 5 dicas técnicas relevantes para a tecnologia e nível escolhidos. Não entregue a solução — apenas oriente.

## 📦 Entregáveis Esperados
Descreva o que deve ser entregue (ex: repositório GitHub, arquivo, endpoint funcional, etc.)

## 🔗 Recursos Recomendados
Sugira de 2 a 4 recursos fictícios ou reais (documentação oficial, artigos, libs) úteis para este desafio.

---

**Regras para calibrar o desafio por nível:**
- **Iniciante:** foco em lógica básica, estruturas simples, sem frameworks complexos
- **Intermediário:** uso de frameworks, integração com APIs ou banco de dados, boas práticas
- **Avançado:** arquitetura, performance, segurança, padrões de projeto, escalabilidade

Ao final, adicione uma mensagem motivacional curta no estilo DIO: "Bora codar! 🚀"
